## Техническое задание: TODO Visualizer
- Разработать расширение для VS Code для поиска TODO-комментариев в файлах проекта.
- Находить комментарии с TODO и сохранять текст задачи и номер строки.
- Выводить найденные задачи в отдельной панели.
- Показывать, в каком файле находится каждая задача.
- Добавить команду для запуска поиска и отображения результатов.
- Использовать TypeScript и VS Code API.
- Для отображения результатов использовать HTML.

## Блок схема работы плагина
A(Запуск плагина) $\Longrightarrow$ B(Получение открытых файлов)  
    B $\Longrightarrow$ C(Поиск TODO)  
    B $\Longrightarrow$ D(Поиск FIXME)  
    C $\Longrightarrow$ E(Сохранение в массив TODO)  
    D $\Longrightarrow$ F(Сохранение в массив FIXME)  
    E $\Longrightarrow$ G(Создание панели Webview)  
    F $\Longrightarrow$ G  
    G $\Longrightarrow$ H(Вывод найденных комментариев)  
    H $\Longrightarrow$ I(Завершение)
